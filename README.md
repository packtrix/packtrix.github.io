# packtrix.github.io

The Packtrix website, served at **https://packtrix.github.io/**.

Don't edit it here: the site is built from [`site/`](https://github.com/packtrix/packtrix/tree/main/site) and [`docs/`](https://github.com/packtrix/packtrix/tree/main/docs) in [packtrix/packtrix](https://github.com/packtrix/packtrix), and published here on every merge to `main` there.
